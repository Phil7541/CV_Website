My personal CV and portfolio website, built to showcase my skills, education, work experience, and software development projects.

## About

This project started as my first fully-fledged website and was originally created as an opportunity to develop my knowledge of HTML and CSS.

As the project developed, I introduced **Vue.js** and a JSON-based content structure to make the website more dynamic and maintainable. The site now generates its CV sections and navigation from the same data source, allowing the content to be updated without modifying the page structure.

The project has also given me practical experience with responsive web design, semantic HTML, CSS organisation, JavaScript, Vue.js, and deploying websites using GitHub Pages.

## Technologies

* HTML5
* CSS3
* JavaScript
* Vue.js 3
* JSON
* Git / GitHub
* GitHub Pages

## Features

* Responsive layout for mobile, tablet, and desktop
* Dynamically generated CV sections using Vue.js
* JSON-based content management
* Dynamic navigation generated from CV sections
* Active navigation indicator based on the current section
* Smooth scrolling navigation
* Responsive navigation layout
* Downloadable PDF version of my CV
* Accessibility, SEO, and best-practice optimised
